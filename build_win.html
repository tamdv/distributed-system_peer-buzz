🪟 Build Flutter → Windows Installer

Hướng dẫn đóng gói ứng dụng Flutter thành file cài đặt Windows

PeerBuzz · vn.vnpt.ONEDiscovery
✦

Yêu cầu môi trường

  • 🖥️
    Windows machine — bắt buộc, không thể cross-compile từ macOS/Linux
  • 🔧
    Visual Studio 2022 — cần workload "Desktop development with C++"
  • 🐦
    Flutter SDK — phiên bản stable, đã bật Windows desktop support
  • 📦
    Inno Setup (option A) hoặc package msix (option B) — để tạo installer
1

Kiểm tra môi trường

Chạy trên máy Windows, kiểm tra Flutter đã nhận đủ toolchain:

cmd / PowerShell
flutter doctor
Cần thấy [✓] Windows Version và [✓] Visual Studio – develop Windows apps.
Nếu thiếu Windows support, chạy thêm:
cmd / PowerShell
flutter config --enable-windows-desktop
2

Build executable (release)

cmd / PowerShell – từ thư mục gốc project
cd peerbuzz
flutter build windows --release
Output tại: build\windows\x64\runner\Release\
Thư mục chứa file .exe + toàn bộ DLL cần thiết.
Chạy thử trực tiếp
build\windows\x64\runner\Release\peerbuzz.exe
3

Đóng gói thành Installer

📦 Inno Setup Khuyên dùng
Miễn phí, đơn giản, ra file .exe cài đặt thông thường

1. Tải Inno Setup tại jrsoftware.org/isdl.php
2. Tạo file script setup.iss:

setup.iss
[Setup]
AppName=PeerBuzz
AppVersion=1.0.0
DefaultDirName={autopf}\PeerBuzz
OutputBaseFilename=PeerBuzz-Setup
Compression=lzma2
SolidCompression=yes

[Files]
Source: "build\windows\x64\runner\Release\*"
DestDir: "{app}"
Flags: recursesubdirs

[Icons]
Name: "{autoprograms}\PeerBuzz"
Filename: "{app}\peerbuzz.exe"
Name: "{autodesktop}\PeerBuzz"
Filename: "{app}\peerbuzz.exe"

[Run]
Filename: "{app}\peerbuzz.exe"
Description: "Launch PeerBuzz"
Flags: postinstall

3. Mở Inno Setup IDE → Compile → ra PeerBuzz-Setup.exe

4

Tóm tắt luồng

flutter build windows --release
→
Release\ folder
→
Inno Setup
→
PeerBuzz-Setup.exe
💡

Lưu ý quan trọng

  • ⚠️
    Phải build trên máy Windows thật hoặc VM Windows — macOS không thể build Windows app.
  • 📁
    Copy toàn bộ thư mục Release\ vào Inno Setup — không chỉ file .exe. App cần DLLs đi kèm.
  • 🔏
    MSIX với sign_msix: false vẫn cài được trên máy dev (developer mode). Deploy qua portal cần code signing certificate.
  • 🔄
    Mỗi lần update app: chỉ cần tăng versionCode trong pubspec.yaml, build lại, recompile Inno Setup.
